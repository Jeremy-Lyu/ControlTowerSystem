Business Design One-Pager · Example Data

Manufacturing Control Tower · 业务设计一页纸

给业务 / 面试官：3 分钟建立心智模型——我们为谁、解决什么经营决策、核心指标如何下钻到行动，以及刻意不做的边界。

一句话 用统一口径把「集团经营结果 → 工厂资源与执行 → 车间现场根因 → 行动闭环」接到 VCS 产量成本测算上；目标一律等于当月测算，而不是拍脑袋固定红线。

1. 为谁、解决什么决策

主要用户

  • 集团经营 / 成本：哪家工厂在抬高转换成本？
  • 工厂厂长：加班与方案执行为何偏离？
  • 总装 / 物流：缺件停线落到哪个供应商？
  • 计划 / 财务：测算与实际如何对账、何时校准？

要改变的行为

  • 周会用同一套数做资源取舍
  • 超阈值（成本 ±5%、产量 ±2%）触发校准，而不是争论感觉
  • 异常自动生成行动项并指定责任角色
  • 复制到新工厂靠配置包与就绪度，而不是重做报表

2. 决策链（演示故事 = 设计本身）

集团成本红灯→ A 工厂加班 / 执行率→ 总装缺件→ 供应商 S07→ VCS 桥梁对账→ 行动闭环

活系统右上角「演示故事」约 5 分钟走完。核心演示 6 页；其余为扩展页（职能 / 治理），证明可扩展，不是当前故事核。

3. 核心演示 6 页 + 扩展

页首屏只回答一个问题关键 KPI
集团总览谁在拉高集团单车转换成本？单车成本、产量达成、OTD、单车电耗
工厂视图钱、加班、方案执行哪里歪了？单车成本、加班率、VCS 执行率、JPH、OEE、外购件缓冲
总装停线主要因缺件吗？落到哪一零件？停线时长、缺件次数、返修、节拍
物流哪家供应商拖累准时率？到货准时率、外购件缓冲天数、线边<4h
VCS 联动偏差如何拆成摊薄 vs 花费？方案跑偏在哪？总额、单车、回测、桥梁、JPH×班次、PBS
异常行动预警是否变成可关闭的待办？行动状态 / 责任角色

扩展页：焊装/涂装/冲压、质量/能源/人力/维护/安全、成本科目表、计划交付、数据治理、指标口径库、根因、对标。全库注册 58 项指标；面试与业务讲解只抓上表。

4. 核心 12 个 KPI（业务必懂）

KPI为何存在目标逻辑
单车转换成本经营结果主指标（17 科目，不含材料）= VCS 当月测算
转换成本总额与单车拆开：看绝对值是否破阈值= VCS 测算；回测 ±5%
产量达成率欠产会抬高单车（摊薄）≥98%；回测产量 ±2%
加班率贵不贵的人力侧= VCS 测算（非固定 ≤8%）
VCS 方案执行率有没有按推荐 JPH×班次跑≥90%
JPH 达成 / OEE节奏 vs 设备有效利用（两个问题）计划档 / ≥85%
总装停线 / 缺件次数现场损失与根因入口≤30 分/班；≤1 次/班
供应商到货准时率缺件的上游≥95%
外购件缓冲天数零部件库存天数（≠ 车身 PBS）1.5–2.5 天
车间间缓存（PBS 等）VCS R1 台数上限≤ 有效上限
单车电耗 / HPV能源与工时效率= VCS 测算
测算-实际偏差治理门禁：何时强制校准成本 ±5% / 产量 ±2%
两种「缓冲」不要混 外购件缓冲天数 = 零部件库存可支撑天数；车间间缓存（PBS/WBS 等） = 车身台数 vs 有效上限。A 工厂可同时出现「外购件缓冲偏紧」与「PBS 已满」——对象不同。

5. 术语 20 秒

  • VCS：产量—成本测算（推荐 JPH 档×班次、线体加班、17 科目成本）；本演示消费测算结果，不调用求解器。
  • FULL_COST（月） vs 年度基准包：不可直接比；敏感性图已标注口径。
  • R4：人均加班 36h 常规 / 60h 上限；超限有溢价。

6. 刻意不做（范围控制）

  • 不接真实 MES/ERP；不部署生产云。
  • 不内嵌 VCS 求解器（情景滑条为线性示意）。
  • 第一波不做全量预测/仿真、不做每国定制整套 BI。
  • 维护/安全等职能页证明可扩展，不是故事核。
